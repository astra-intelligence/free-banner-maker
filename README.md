# Free Banner Maker

> Generate professional social media banners instantly — **no sign-up, no API key, no install required.**

**[🚀 Try it now →](https://astra-intelligence.github.io/free-banner-maker/)**

Create beautiful, custom banners for all major social media platforms directly in your browser. Free, fast, and private.

## Features

- **7 Platform Sizes** — Twitter/X, LinkedIn, Instagram, Instagram Story, YouTube, YouTube Thumbnail, Facebook
- **4 Visual Styles** — Modern, Minimal, Bold, Gradient
- **Custom Colors** — Pick any brand color for background and text
- **Brand Identity** — Add your brand name and tagline
- **SVG + PNG Download** — Download as scalable SVG or high-res PNG
- **Zero Friction** — No accounts, no API keys, no data uploaded to any server
- **Progressive Web App** — Works offline after first visit
